# Data sources

| Material | Source and use |
| --- | --- |
| MLB teaching CSV | The original lesson attributes the sample to MLB.com. It is excluded because redistribution permission was not established; season values were not independently verified. See the [local data setup](python-basics/data/README.md). |
| Pokémon JSON files | Trimmed/flattened PokéAPI examples retained from the original workshop. Their retrieval date is not recorded. See the PokéAPI attribution and BSD notice in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md). |
| Offline weather JSON and CSV | Matching sets of 72 illustrative classroom records for Dayton, retained from the workshop. These are not downloaded Open-Meteo forecasts or observations. |
| Live weather requests | The notebook uses Open-Meteo, selecting fields, renaming columns, and parsing timestamps. Attribution and license links are in [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md). |

No MLB data or its generated tables/charts should be committed without redistribution permission. The original classroom materials have no repository-wide reuse license; this repository does not assign one on the club's behalf.
